# Permutation Equivariance Limits Frozen Time-Series Foundation Model Features for RUL Estimation

Code for a public-data replication of **arXiv:2606.11990** ("Time-Series Foundation Model
Embeddings for Remaining Useful Life Estimation", El-Ghoussani, De Vita, Naumann &
Belagiannis, EUSIPCO 2026), extended with the uncertainty analysis the original does not
report.

The original work uses a frozen **Chronos-2** backbone as a feature extractor and trains a
small MLP head to predict Remaining Useful Life, on proprietary industrial telemetry. This
study identifies a structural property of that backbone and quantifies its consequences on
the public **NASA C-MAPSS FD001** benchmark.

## Reproduce

```bash
bash run.sh                # everything, from a clean checkout
bash run.sh fetch-data     # data only
```

Python via `uv`, exact versions in `requirements.lock`. Environment, seeds, backbone
revision and device land in `run_manifest.json`.

**Phases must run as separate processes.** torch and LightGBM cannot coexist in one
process on macOS — whichever is imported second segfaults on its first threaded kernel.
`src/ompguard.py` enforces this and fails loudly instead of crashing, and documents the
measurements behind it. Do not merge the `run.sh` invocations.

## Findings

All at the primary look-back L=30 on 30 held-out engines (450 truncation points), with
by-unit clustered bootstrap intervals throughout and every head arm averaged over 5
training seeds.

- **Chronos-2 is exactly permutation-equivariant across variates.** Permuting the sensor
  channels of an input permutes the output embeddings correspondingly, to 3.3 × 10⁻⁶ on real
  windows, while the permutation displaces the embeddings by 6.79 — a ratio of 2,035,369.
  The backbone encodes nothing about *which* sensor a channel is, so a variate-symmetric
  read-out makes a channel-scramble control mathematically vacuous. Reproduce with `uv run
  python -m src.equivariance`.
- **The accuracy claim does not replicate.** At L=30 the frozen-embedding arm is worse than
  a fixed-hyperparameter LightGBM over seven window statistics (+5.98 RMSE, [+1.60,
  +10.07]). At L=80, the context the original identifies as its optimum, the two reach
  parity and never separate. Our baselines are untuned while the original's were tuned,
  which biases *towards* the TSFM arm.
- **Pretraining is indistinguishable from random features at short context.** Under the
  specified head, 5 seeds, and a hyperparameter-free ridge probe, the frozen representation
  never separates from a fixed random *linear* projection of the same window at L=30. It
  does separate at L=80.
- **The uncertainty is not usable as reported.** A nominal 90% interval attains 36.9%
  coverage, and the original's MSE head emits no interval at all. Split conformal restores
  approximately nominal coverage at 3.41× the width against 1.49× for the baseline, and
  inverts rather than removes the regime-conditional failure.

None of the original paper's numbers appear in any of our results tables.
